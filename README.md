# java-filmorate
Template repository for Filmorate project.

Стек технологий:
Java 21
Spring Boot
JDBC (JdbcTemplate)
База данных H2
Maven
Lombok
JUnit 5, Postman (тестирование)


Функциональность группового проекта:
В рамках командного этапа проекта реализованы следующие фичи. 

Удаление фильма и пользователя по идентификатору вместе со связанными данными (лайки, дружба).
DELETE /users/{userId} — удаляет пользователя по идентификатору
DELETE /films/{filmId} — удаляет фильм по идентификатору


Добавление режиссёров в фильмы. В информацию о фильме добавлены режиссёры. 
Реализован CRUD для режиссёров и вывод фильмов режиссёра
с сортировкой по году выпуска или количеству лайков.
GET /films/director/{directorId}?sortBy=[year,likes] — фильмы режиссёра, отсортированные по году или лайкам
GET /directors — список всех режиссёров
GET /directors/{id} — получение режиссёра по id
POST /directors — создание режиссёра
PUT /directors — изменение режиссёра
DELETE /directors/{id} — удаление режиссёра


Вывод самых популярных фильмов по жанру и годам. 
Вывод топ-N фильмов по количеству лайков с фильтрацией по жанру и году выпуска. Выборка выполняется одним SQL-запросом.
GET /films/popular?count={limit}&genreId={genreId}&year={year}


Функциональность «Поиск»
Поиск фильмов по подстроке — по названию фильма и/или имени режиссёра, без учёта регистра.
Результаты отсортированы по популярности.
GET /films/search?query={text}&by={director,title}
query — текст для поиска
by — где искать: title (по названию), director (по режиссёру) или оба значения через запятую


Функциональность «Общие фильмы». Вывод фильмов, которые лайкнули оба пользователя, с сортировкой по популярности.
GET /films/common?userId={userId}&friendId={friendId}
userId — идентификатор пользователя, запрашивающего информацию
friendId — идентификатор пользователя, с которым сравнивается список фильмов


Функциональность «Отзывы».
Отзывы на фильмы: отзыв имеет тип (положительный/негативный) и рейтинг полезности.
Пользователи оценивают отзывы лайками и дизлайками, отзывы сортируются по рейтингу полезности.
POST /reviews — добавление отзыва
PUT /reviews — редактирование отзыва
DELETE /reviews/{id} — удаление отзыва
GET /reviews/{id} — получение отзыва по идентификатору
GET /reviews?filmId={filmId}&count={count} — отзывы по фильму (если фильм не указан — все; count по умолчанию 10)
PUT /reviews/{id}/like/{userId} — поставить лайк отзыву
PUT /reviews/{id}/dislike/{userId} — поставить дизлайк отзыву
DELETE /reviews/{id}/like/{userId} — удалить лайк отзыва
DELETE /reviews/{id}/dislike/{userId} — удалить дизлайк отзыва


Функциональность «Лента событий».
Просмотр последних событий на платформе: добавление и удаление друзей, лайки и отзывы друзей пользователя.
События хранятся в отдельной таблице (типы: LIKE, REVIEW, FRIEND; операции: ADD, REMOVE, UPDATE).
GET /users/{id}/feed — возвращает ленту событий пользователя


Функциональность «Рекомендации».
Простая рекомендательная система на основе коллаборативной фильтрации: находится пользователь
с максимальным пересечением по лайкам, и рекомендуются фильмы, которые он лайкнул, а текущий пользователь — ещё нет.
GET /users/{id}/recommendations — возвращает рекомендованные фильмы


Базовая функциональность (предыдущие спринты)
CRUD для фильмов и пользователей: POST/PUT/GET /films, POST/PUT/GET /users
Лайки фильмов: PUT /films/{id}/like/{userId}, DELETE /films/{id}/like/{userId}
Дружба: PUT /users/{id}/friends/{friendId}, DELETE /users/{id}/friends/{friendId},
GET /users/{id}/friends, GET /users/{id}/friends/common/{otherId}
Справочники жанров и возрастных рейтингов MPA: GET /genres, GET /genres/{id}, GET /mpa, GET /mpa/{id}
Валидация входных данных и централизованная обработка ошибок (400, 404, 500)
